`--gramstat` enables Gramstat in `ton-index-clickhouse` and `ton-index-postgres` (`collect_gramstat` internally). The shared `IndexScheduler` calls TON's `calculate_global_balance_at_anchor()` on the loaded MC and shard states. Each MC produces one snapshot in `gramstat.total_supply`: `mc_seqno`, `gen_utime`, `total`, `accounts`, `dispatch_queue`, `unprocessed_messages`, `unrecovered_validator_fees`. Amounts are exact integer nanoTON; `total` is the sum of the four components.

In ClickHouse, `gramstat` is a database: amounts use `Decimal(38,0)`, time uses `DateTime('UTC')`, and the table uses monthly `ReplacingMergeTree` partitions ordered by `(gen_utime, mc_seqno)`. In PostgreSQL, `gramstat` is a schema: amounts use `numeric(38,0)`, identifiers and Unix-second time use `bigint`, and snapshots commit atomically with blocks, with `mc_seqno` as the primary key. Historical backfill uses `--from N --to M`. Hourly/daily charts select the last snapshot per UTC interval using `argMax` in ClickHouse or `DISTINCT ON` in PostgreSQL, breaking equal-second ties by `mc_seqno`.
